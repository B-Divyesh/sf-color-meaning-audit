Installation note

Add the extension in three steps.

  1. Extract the downloaded ZIP into its own folder.
  2. Open chrome://extensions and switch on Developer mode.
  3. Choose Load unpacked and select the extracted folder.

Run your first check. Open a chart or dashboard. Choose Signal Check from the toolbar, then choose Check this page.
