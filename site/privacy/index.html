Plain-language policy · effective August 28, 2026

Your page stays in your browser.

Signal Check checks the visible page in the browser. It has no account or analytics service.

What the extension processes

When you choose “Check this page,” the extension reads visible page markers and a temporary visible-tab image. The check notes open in that tab. The image is used for the check and is not an upload.

What the extension stores

The selected color-vision view and the last check count stay in browser-local extension storage. Use “Clear last check” in the popup to remove the last count.

What the demo stores

The demo saves only its own temporary sample. Reset demo removes it. The demo does not read or change extension storage.

Website requests

The demo requests files from this site only. It has no analytics, cookies, remote fonts, or third-party runtime scripts.

Contact and changes

Questions or reports can be opened in the project’s public issue tracker. Material policy changes will be dated on this page.
